# Learning System

This is the same retrieval and relearning workflow used in Semester 2, with an independent Semester 3 queue.

1. Ingest an original source into `<course>/raw/`.
2. Write a standalone topic note, `CONTEXT.md`, and course graph update.
3. Add the note as `first pass pending — note generated YYYY-MM-DD` to `review-dashboard.md`. Leave all checkpoint dates blank.
4. Run closed-book first-pass coaching. Only its actual completion starts the review chain.
5. Chain `D+1`, `D+3`, `D+7`, `D+14`, and `D+30` from the actual completion date of the preceding checkpoint, recording actual dates in the cells and the next planned date in Status.
6. Record weak answers in the mistake ledger, then refresh `weekly-calendar.md`.

The dashboard is the completion record; the calendar is a current view. Read `../AGENTS.md` for missed-review repair, prerequisites, and session rules.
